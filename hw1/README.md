# HW1: лексер Funny

Лексер для Funny на Clojure.

## Запуск

Все команды выполняются из каталога `hw1`:

```sh
lein test
lein run -m hw1.main tokens "function f() returns r:int { r = 0; }"
lein run -m hw1.main table
lein run -m hw1.main examples
```

Если не передать исходный текст после `tokens`, программа читает его из stdin. Команда `table` печатает одну EDN-карту `{:start :trap :skip-types :state-counts :states}` (начальное состояние, ловушка, пропускаемые типы, размеры и строки переходов), а `examples` запускает примеры.

Правила токенов, устройство автомата и результаты измерения покрытия описаны в [отчёте](REPORT.md).

В комментарии `//` допустим любой символ (в том числе не-ASCII) до конца строки; вне комментариев не-ASCII по-прежнему лексическая ошибка (ловушка).
