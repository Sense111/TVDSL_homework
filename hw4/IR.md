# Формат IR (HW4)

Трёхадресный код. Один модуль = вектор функций. Все значения `int` (32 бита со знаком, переполнение по модулю 2^32) или `int[]` (неизменяемый массив).

## Функция

```clojure
{:name "f"
 :params ["x" "a"]          ; имена параметров по порядку
 :returns ["r"]             ; имена возвращаемых переменных по порядку
 :var-types {"x" :int "a" :int-array "r" :int "%t1" :int ...}  ; тип каждой переменной и временной
 :code [instr ...]}         ; линейный код
```

## Операнды

- целое число (`Long`) — константа;
- строка — переменная. Временные начинаются с `%` (`%t1`, `%t2`), чтобы не пересекаться с именами пользователя. Переменные пользователя (параметры, возвраты, локальные) имеют имена исходной программы.

## Инструкции (векторы)

| Инструкция | Смысл |
|---|---|
| `[:label L]` | метка (начало базового блока) |
| `[:mov dst a]` | `dst = a` (для массивов — присваивание ссылки: массивы неизменяемы, копия не наблюдаема) |
| `[:neg dst a]` | `dst = -a` |
| `[:bin op dst a b]` | `dst = a op b`, `op` ∈ `:add :sub :mul :div`; `:div` — деление с усечением к нулю, на 0 — исключение |
| `[:aget dst arr i]` | `dst = arr[i]`; индекс вне границ — исключение |
| `[:aset dst arr i v]` | `dst = копия arr с arr[i] = v` (функциональное обновление), индекс вне границ — исключение |
| `[:len dst arr]` | `dst = length(arr)` |
| `[:call dsts name args]` | вызов функции модуля; `dsts` — вектор переменных (по числу возвращаемых значений) |
| `[:jmp L]` | безусловный переход |
| `[:cjmp cmp a b Lt Lf]` | если `a cmp b` — на `Lt`, иначе на `Lf`; `cmp` ∈ `:lt :le :gt :ge :eq :ne` |
| `[:ret]` | возврат; значения — текущие значения переменных из `:returns` |
| `[:trap kind]` | аварийная остановка (`:assert`, `:assume`) |

Терминаторы блока: `:jmp`, `:cjmp`, `:ret`, `:trap`. Условия `and`/`or`/`->`/`not` раскрываются в переходы с ленивым вычислением (булевых значений в IR нет).

## Побочные эффекты и исключения

Могут бросать исключение: `:div` (деление на 0), `:aget`/`:aset` (индекс вне границ). Оптимизации не должны убирать такие инструкции, если нельзя доказать, что исключения не будет, и не должны менять порядок исключений. `:call` считается имеющим эффекты и не удаляется.

## CFG (`hw4.cfg`)

```clojure
{:entry "B0"
 :order ["B0" "L1" ...]     ; порядок блоков для вывода
 :blocks {"B0" {:id "B0" :instrs [..., терминатор] :succs ["L1" "L2"]} ...}}
```

Блок не содержит меток внутри; последняя инструкция — терминатор. Предшественники вычисляются функцией `preds`.

## Параметры запуска

Опции генерации и оптимизаций передаются картой: `{:asserts false :const-prop true :algebra true :dce true :cse false}`.
