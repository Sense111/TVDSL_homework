# HW3: имена и типы Funny

Семантический анализатор на Clojure. Использует парсер из [HW2](../hw2) (и лексер из [HW1](../hw1)): текст программы → AST → аннотированный AST + список ошибок.

## Запуск

Из каталога `hw3`:

```sh
lein test
lein run -m hw3.main examples/ok.funny    # ошибок нет, код 0
lein run -m hw3.main examples/bad.funny   # ошибки с позициями, код 1
```

CLI печатает `{:ast ... :errors [...]}`. Из кода: `(hw3.types/check-source text)` (с разбором) или `(hw3.types/check module-ast)`. Синтаксические ошибки HW2 попадают в тот же список с `:phase :syntax`; проверка типов выполняется для успешно разобранной части.

## Что поддерживается

- **Типы:** `int`, `int[]` (в AST `:int`, `:int-array`) и `bool` для условий (переменных типа `bool` нет, как в спецификации Funny). Служебные типы: `:error` (ошибка уже сообщена, каскадные сообщения подавляются) и `:tuple` (вызов в кортежном присваивании).
- **Неявные локальные (T0):** имя, которому присваивают в теле и которое не объявлено в `uses`, неявно становится локальной; её тип выводится по первому присваиванию (как в эталонах `project/examples`). Чтение необъявленного имени до присваивания — `:unknown-name`. Такие локальные попадают в `:locals` функции с `:inferred? true`.
- **Таблицы символов:** область — одна функция; виды символов `:param`, `:return`, `:local`. Повторные объявления (параметры, возвраты, локальные, функции модуля, имя `length`), неизвестные имена и функции, запись в параметры (в том числе `a[i] = v`) запрещены.
- **Видимость в контрактах:** `requires` — параметры; `ensures` — параметры и возвраты; тело, `while`/`invariant` — всё.
- **Выражения:** арифметика и унарный минус — `int`; сравнения → `bool`; `and`/`or`/`->`/`not` — `bool`; индексация — `int[]` с индексом `int`; вызовы: число и типы аргументов, встроенная `length(int[]) -> int`, рекурсия; многозначный вызов допустим только в кортежном присваивании (число целей и типы должны совпадать).
- **Операторы:** присваивание (типы цели и значения совпадают), `a[i] = v` (цель `int[]`, индекс и значение `int`; вложенные индексы `a[i][j]` — ошибка, вложенных массивов нет), `if`/`while`/`assert`/`assume`/`invariant` требуют `bool`.
- **Бонус — вывод типов локальных:** `uses t` без аннотации получает тип из первого присваивания (`t = p + 1` → `int`, `b = a` → `int[]`, `c[0] = 1` → `int[]`, кортежное присваивание берёт типы из сигнатуры). Противоречащее присваивание, чтение до присваивания, значение типа `bool` и переменная, которой так и не присвоили значение, — ошибки `:cannot-infer`/`:type-mismatch`. Порядок «первого» присваивания — текстовый.
- Литерал `int` вне 32-битного диапазона в коде (не в контрактах) — ошибка `:out-of-range`; `-2147483648` допустим.
- Синтаксис входа — как у парсера HW2: `function` перед именем функции необязателен (допустим и вариант upstream `funny.ru.md`), локальные перечисляются в `uses`, см. [grammar.md](../hw2/grammar.md).
- Формулы, кванторы, `forall/exists` не поддерживаются (их нет и в парсере HW2).

## Формат аннотированного AST

Это AST HW2 (карты с `:node` и `:position`) с добавлениями:

| Где | Поле |
|---|---|
| любое выражение (`:int :bool :name :unary :binary :index :call`) | `:type` ∈ `:int :int-array :bool :error` (у вызова в кортежном присваивании `:tuple` и `:return-types`) |
| `:name` | `:symbol` ∈ `:param :return :local` |
| `:call` | `:signature {:params [...] :returns [...]}` |
| `:function` | `:signature`; `:locals` с разрешёнными `:type` и `:inferred?` |
| `:assign`, `:array-update` | `:target-type`, `:inferred?` (если первое присваивание определило тип) |

## Ошибки

`{:phase :semantic :kind <ключ> :message "..." :line n :column m}`; позиция — позиция узла AST (для бинарных операторов — токен оператора, для индексации — `[`). Ключи `:kind`: `:unknown-name :unknown-function :duplicate-declaration :not-visible :read-only :type-mismatch :arity :cannot-infer :out-of-range`. После ошибки анализ продолжается, ошибки отсортированы по позиции (вместе с синтаксическими). Если есть синтаксические ошибки, сообщения `:cannot-infer` не выдаются: в усечённом AST они были бы ложными.
