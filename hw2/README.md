# HW2: парсер Funny

Парсер на Clojure разбирает подмножество Funny и использует лексер из [HW1](../hw1).

## Запуск

Команды выполняются из каталога `hw2`:

```sh
lein test
lein run -m hw2.main examples/basic.funny
```

CLI печатает карту `{:ast ... :errors [...]}`. При синтаксических ошибках AST содержит разобранную часть программы, ошибки включают позиции, а процесс завершается с кодом `1`.

## AST

Узел AST — Clojure-карта с тегом `:node`. Используются узлы `:module`, `:function`, `:block`, `:assign`, `:array-update`, `:tuple-assign`, `:if`, `:while`, `:assert`, `:assume` и узлы выражений. Позиции исходника нумеруются с единицы.

Поддерживаемая грамматика, приоритеты операторов, восстановление после ошибок и ограничения парсера описаны в [grammar.md](grammar.md).
