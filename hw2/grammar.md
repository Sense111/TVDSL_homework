# HW2: грамматика подмножества Funny

Парсер реализован методом рекурсивного спуска и строит AST в виде Clojure-карт с тегом `:node`. Ниже описано подмножество Funny, поддерживаемое в этом задании. Семантическая проверка и проверка типов не выполняются.

~~~ebnf
program       = { function } ;
function      = "function" identifier "(" [ variable { "," variable } ] ")"
                [ "requires" expression ]
                "returns" variable { "," variable }
                [ "ensures" expression ]
                [ "uses" local { "," local } ] statement ;
variable      = identifier ":" type ;
local         = identifier [ ":" type ] ;
type          = "int" | "int" "[" "]" ;
statement     = block | assignment | if | while | assert | assume ;
block         = "{" { statement } "}" ;
assignment    = identifier { "[" expression "]" } "=" expression ";"
              | identifier { "," identifier } "=" call ";" ;
if            = "if" "(" expression ")" statement [ "else" statement ] ;
while         = "while" "(" expression ")" [ "invariant" expression ] statement ;
assert        = "assert" expression ";" ;
assume        = "assume" expression ";" ;
call          = identifier "(" [ expression { "," expression } ] ")" ;
~~~

Приоритет операторов выражений от наивысшего к низшему:

~~~text
основное выражение/индекс/вызов → унарный минус → * / → + - → сравнения → not → and → or → ->
~~~

Бинарные операторы группируются слева направо, кроме `->`, который группируется справа налево. Сравнение может содержать не более одного оператора сравнения между арифметическими выражениями. Запись обновления массива `a[i] = v;` представляется в AST узлом `:array-update` с именем массива, путём индексов и новым значением.

При синтаксической ошибке парсер указывает ожидаемую конструкцию, найденный токен и позицию (строка и столбец, нумерация с 1). Внутри блока он пропускает токены до `;`, `}` или конца файла; на верхнем уровне — до следующей функции или конца файла. Восстановление не зацикливается.

## Что не входит в подмножество

- Объявления и ссылки на формулы, кванторы и отдельная полная грамматика предикатов.
- Семантические проверки: объявление имён, типы, число аргументов вызова, границы массивов и возможность изменения параметров.
- Преобразование вложенных обновлений массива в цепочку функциональных копирований; индексы сохраняются в AST.
- Объявления функций должны использовать форму с ключевым словом `function`. В примерах проектной стадии репозитория может использоваться отдельный более ранний синтаксис.
